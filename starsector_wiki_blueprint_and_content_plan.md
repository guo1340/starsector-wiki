# Starsector Wiki — Full Project Blueprint

## Project Vision

Create a premium-quality standalone wiki website for the game entity["video_game","Starsector","space sandbox strategy RPG"] under the GameWikiHub ecosystem.

The goal is NOT to imitate a traditional MediaWiki installation.
Instead, the site should feel:

- modern
- atmospheric
- immersive
- readable
- highly searchable
- optimized for SEO
- lightweight and static
- designed for long session reading

The Project Zomboid wiki serves as the architecture reference:

- static generated pages
- structured JSON/JS data
- category pages
- sidebar navigation
- ad placements
- searchable content blocks
- responsive design
- expandable content later

But the Starsector version should have a distinct visual identity.

---

# Core Identity

## Theme Direction

Starsector is:

- lonely
- industrial
- tactical
- mysterious
- deep
- sandbox-driven
- post-collapse sci-fi
- fleet-oriented

The website should feel like:

> an abandoned interstellar database recovered from a collapsing sector.

NOT clean futuristic Apple-style sci-fi.

Instead:

- dark terminals
- radar screens
- holographic overlays
- deep-space ambience
- faction propaganda aesthetics
- navigation computer interfaces
